### Performance Evaluation of Interconnect Technologies for AI Scale-Up Computing: UAL vs UALoE/SUE vs RoCE

Speakers: Srihari Vegesna (Upscale AI), Srinivas Gangam (Upscale AI)

### Capacity Aware Adaptive Routing

**Links:** [Abstract](https://2025ocpglobal.fnvirtual.app/a/schedule/6897/) · [Session recording](https://www.youtube.com/watch?v=LFigppFFDRc) · [Materials](https://github.com/facebook/fboss)

Speakers: Yikai Lin (Meta), Midhun Somasundaran (Meta)

- **Why**: This is exactly the failure-mode analysis a fabric designer needs: what breaks in local-load-aware adaptive routing at Meta's topology scale, and the fix. Real production architecture, open-source linkage (FBOSS).
- **What**: Meta's next-generation backend routing design. Their existing adaptive routing scheme (ARS), which relies on local load awareness, degrades on larger topologies — parallel links plus shallow-buffer switches plus silent capacity loss from remote link failures. The new approach combines remote capacity information with local-congestion-aware spray. (from abstract only)
- **How**: Dynamically adjusts load balancing based on end-to-end link capacity so partial failures reduce performance gracefully; adds algorithms for merging ARS groups and uses non-load-aware ECMP spray groups to address scaling limits.
- **Where applicable**: Meta-specific topology and switch-buffer assumptions (shallow-buffer Ethernet, parallel-link spines), but the technique — capacity-aware rather than purely queue-aware spray — is a general idea for any large Clos fabric. FBOSS reference code is linked from the session materials.

## Themes

- **AI backend fabrics own the agenda.** Nearly every core session bends to one problem: building reliable, non-blocking Ethernet fabrics for 100K+ GPU clusters — SRv6 path control (Microsoft), capacity-aware adaptive routing (Meta), UEC 1.0, scale-up vs. scale-out interconnect comparisons. BGP+ECMP is being explicitly declared insufficient, and the replacements (SRv6, adaptive spray, transaction-level load balancing) are the live design frontier.
- **Optics reliability is the new bottleneck.** 30,000-FIT pluggables (Zero Flap), ML-based SerDes failure prediction (INSPECT), multi-month CPO/LPO reliability testing (Meta), and silicon-based cable length measurement all attack the same realization: at AI scale, link failures — not bandwidth — dominate downtime and job restarts.
- **Telemetry becomes a first-class fabric feature.** CSIG (congestion location signaling), High-Frequency Streaming Telemetry, host/line-side optical telemetry, and SerDes telemetry form a pattern: in-band, line-rate, application-context measurement feeding congestion control, load balancing, and predictive maintenance.
- **The open software stack is absorbing routing complexity.** SONiC's Routing workgroup (SRv6, VxLAN multi-homing, FRR 10.x, RIB/FIB separation), Meta's SAI/FBOSS evolution, disaggregated-chassis spines in Azure, and a new open OCS software stack show open networking moving from "box replacement" to owning hard routing and fabric-management problems.
- **Ethernet is contesting every tier.** UALoE/SUE and RoCE press into scale-up against memory-semantic links, SRv6 Ethernet wins the backend at Microsoft and Meta, and eCore brings Ethernet whiteboxes to DCI — while the UAL-vs-Ethernet evaluation shows exactly where Ethernet still loses (small transfers, latency determinism).
- **Hardware identity and attestation are maturing fast.** Caliptra's DICE/DPE identity chain and SPDM's authorization and post-quantum work signal that the RoT layer — the physical anchor for everything the PM cares about in identity — is converging on open, standardized designs with a PQC migration already scheduled.
